1. Executive Summary & Core Platform Architecture

PLUS MAX is a state-of-the-art enterprise resource planning platform engineered specifically for healthcare networks, super-specialty hospitals, and NMC-accredited medical colleges. The platform seamlessly unifies clinical care, academic education tracking, financial billing compliance, pharmacy supply chain, diagnostic lab automation, and multi-tenant SaaS management into a single zero-latency web architecture.

Architectural Layer Technology Stack Key Functionality
Frontend Web App Next.js 14 (App Router), React 18, Tailwind CSS, Lucide Icons, Framer Motion Zero-latency server & client rendering, responsive glassmorphic UI, spatial canvas interfaces.
Graphics & Spatial Visualization WebGPU, WebGL 2.0 Canvas Renderer 360-degree rotatable 3D anatomical human body model, spatial OT floor maps, 3D ward maps.
Backend API Architecture NestJS REST & WebSocket Microservices High-throughput transaction handling, role-based access control (RBAC), LIS machine sync.
Multi-Tenant Data Layer PostgreSQL with Schema Isolation Dedicated tenant_schema_* per hospital ensuring 100% data isolation and zero cross-tenant data bleed.

2. Module Breakdown & Comprehensive Feature Matrix

Module 1: Student Portal (Medical College)

1.1 NMC e-Logbook

Searchable, highly responsive competency tracker mapping the mandatory 2,683 NMC competencies with Knowledge (K), Know How (KH), Show How (SH), and Perform (P) tags. Includes modular forms for DOAP sessions, AETCOM modules, Family Adoption Programme (FAP) visits, and authenticated faculty digital sign-offs.

1.2 Attendance & IA 40% Eligibility

SVG radial progress rings visualizing theory (≥75% threshold) and practical attendance. Real-time Internal Assessment (IA) score grid with automated red alert banners for students falling below the 40% exam eligibility threshold.

1.3 Clinical Postings & 1.4 Fees & Hostel

Interactive rotation spatial calendar with quick log entry. Online fee dues checkout with downloadable PDF receipt generator, hostel room allocation, mess card tracking, and digital QR gate pass generator.

Module 2: Staff & Faculty Portal

2.1 Faculty Logbook E-Sign Desk & 2.2 IA Marks Gradebook

Prioritized inbox view for pending student logbook submissions with batch PIN signing and slide-out frosted glass review modal. Spreadsheet-style gradebook with locked left columns, statistical overlays, red <40% highlights, and PIN 9999 HOD freeze locking.

2.3 Ward Attendance & 2.4 Shift Roster

Touch-optimized quick-toggle roster with 360-degree spatial ward map and automated absentee triggers. Duty timeline, shift swap marketplace, and leave management portal.

Module 3: Doctor EMR & Clinical Portal

3.1 OPD Consult Queue & 3.2 AI Clinical Triage (3D WebGPU)

Frosted glass smart cards with zero-click vitals hover snapshot. Rotatable 3D anatomical human body model rendered via WebGPU canvas with clickable organ nodes, ESI acuity scoring (Critical/Urgent/Stable), and predictive STAT lab pre-orders.

3.3 OT Surgery Schedule & 3.4 E-Prescription Writer

Top-down 360 spatial theater floor map, Gantt timeline with auto prep/cleanup buffers, and surgical team conflict matrix. Drug autocomplete search, hard-stop allergy/interaction guardrails with safe alternatives, 1-tap regimen protocols, and SHA-256 digital pharmacy hand-off.

Module 4: Financial ERP & POS Terminal

4.1 18% GST Invoices & 4.2 Razorpay POS Terminal

Automated SAC code tax routing (SAC 9993 0% Healthcare vs SAC 9997 18% Cosmetic), CGST/SGST vs IGST calculation engine, and compliant credit notes. Direct hardware sync simulator with PCI-DSS card tokenization (tok_rzp_*).

4.3 Insurance TPA Pre-auth & 4.4 Patient Billing

TPA provider integration network, digital pre-auth packaging, emergency cashless bypass, and automated discharge packets. Real-time master folio charge ingestion, pre-discharge review dashboard, and split payment handling.

Module 5: Pharmacy & LIS Diagnostics Module

5.1 Medicine Stock Inventory & 5.2 2D Barcode Dispenser

High-density SKU data grid with frosted amber reorder glows (QOH < Par Level) and multi-store transfers. Simulated 2D barcode hardware reader with metallic blue match verification highlight and hard-stop discrepancy alerts.

5.3 Batch Expiry Tracker & 5.4 LIS Lab Verification

30/60/90 day timeline clustering, FEFO (First-Expire First-Out) enforcement, and reverse PO vendor return routing. Bi-directional analyzer sync (Sysmex & Roche), split-screen dual-pane validation UI, and automated pathologist anomaly flagging.

Module 6: Super Admin SaaS Command Center

6.1 Tenant Provisioner & 6.2 Custom Domain Binding

1-Click onboarding wizard, isolated PostgreSQL schema generation (tenant_schema_*), and automated ICD-10 seed data injection. CNAME/A record DNS visualizer with metallic blue status glow, zero-touch SSL auto-provisioning (Let's Encrypt TLS 1.3), and reverse proxy router.

6.3 Bed Quota Licensing & 6.4 Global System Telemetry Logs

SVG capacity radial progress rings, soft 90% frosted amber & hard 100% admission block enforcement, and modular feature flag toggles. WebGPU infinite-scroll telemetry log stream, real-time AI threat highlighting in red glass panels, and granular query builder.

3. Vercel Cloud Deployment & Execution Guide

Option A: 1-Click Vercel GitHub Deployment (Recommended)
  1. Push repository changes to GitHub: https://github.com/Rajkumarceo/PLUS-MAX-.git
  2. Log into Vercel Dashboard and click Add New Project.
  3. Import Rajkumarceo/PLUS-MAX- repository.
  4. Set Framework Preset to Next.js and Root Directory to apps/web.
  5. Click Deploy. Vercel will build and assign a global production URL (e.g. https://plus-max-web.vercel.app).
Option B: Vercel CLI Terminal Deployment
# 1. Login to Vercel CLI
npx vercel login

# 2. Deploy Project from Root Directory
npx vercel --prod
